## 1. What this is

**Pinjam.in** — a responsive web app for **Politeknik Negeri Batam (Polibatam)** that lets
**Mahasiswa (students)**, **Dosen (lecturers)**, and **Admin** borrow, approve, and manage
classroom equipment (projectors, HDMI cables, remotes, etc.). All UI copy and code comments are
in **Indonesian**.

Core domain: users create **bookings** (`loans`) for classroom items with a start/end date, which
are approved/rejected by a Dosen or Admin, picked up, then returned with a condition report.
The app tracks live stock availability per date, auto-transitions overdue/expired loans, sends
notifications, and offers an admin dashboard/calendar/rules editor.

Created inside **Figma Make**. `README.md` is a short pointer to this file (rewritten as UTF-8).

## 4. Domain model (`src/data.ts`)

- `Role` = `Mahasiswa | Dosen | Admin`
- `Status` = `Menunggu | Disetujui | Ditolak | Dipinjam | Dikembalikan | Terlambat | Dibatalkan | Kedaluwarsa`
- `Kondisi` = `Baik | Rusak Ringan | Rusak Berat | Hilang`
- `User { id, nama, nim_nip, email, role, aktif, hp?, kota?, authId?, legacyId? }`
  - Since Fase 3, `id` **is the Supabase Auth user id** (matching `loan.userId`); `legacyId`
    keeps the old seed id (`u1`, …). `GET /state` returns users from the server directly.
- `Item { id, nama, kategori, deskripsi, stok_total, kondisi }`
- `Loan { id(PJ-xxxx), userId, items[{itemId,qty,kondisiKembali?}], start, end, keperluan, status, approver?, note?, history[], returnNote?, extension? }`
- `Notif { id, userId?, roles?, title, message, at, read, kind }`
- `ChatStatus = Terbuka | Selesai`
- `ChatTicket { id, subject, userId, by, role, status, at, updatedAt, messages[ChatMessage], closedAt?, closedBy? }`
- `ChatMessage { id, userId, by, role, text, at, readBy[] }` — `readBy` = siapa saja yang sudah membaca
- `OCCUPYING = [Disetujui, Dipinjam, Terlambat]` — statuses that hold stock.

`isCampusEmail()` restricts signups to `*@*.polibatam.ac.id` (subdomains allowed).
Dates are `YYYY-MM-DD` strings; helpers: `addDays`, `diffDays`, `fmtDate`, `fmtRange`,
`monthGrid`, `shiftMonth`, `fmtMonth`.

## 5. Business rules (`src/config.ts`, mirrored in server `logic.tsx` DEFAULT_RULES)

```

maxLoanDurationDays: 3         // max loan length
pickupDeadlineDaysAfterStart: 1// approved-but-uncollected → Kedaluwarsa after this
```

Admins edit these via AdminRules; the client persists them to KV `rules` via `PUT /rules`
(`src/config.ts` only supplies the defaults / validation ranges).
**Keep the two default sets in sync** (`src/config.ts` ↔ `supabase/.../logic.tsx`).

## 6. Client state (`src/store.tsx`)

Single React context (`useStore()`) created via `globalThis.__pinjaminCtx` so it survives HMR.
Holds: users, items, categories, loans, notifs, current `me`, page routing, cart, favorites,
toasts, theme (light/dark/system), wallpaper, simulated date (`simDays`).

Key behaviors (**all domain data now comes from the server** — see §11):
- **Auth** (`boot`, `login`, `logout`): seeds the server once (only if empty), restores the
  Supabase session, calls `GET /me` for identity, then loads everything via `GET /state`.
- **Server sync** (`refresh`): reads `GET /state` and exposes `dataStatus` (`loading|ready|error`),
  `dataError`, and `refresh()`. Polls **every 5 s** and on window focus while logged in. A `401`
  during refresh signs the user out; other errors set `dataStatus = 'error'` only **before** the
  first successful load (later failures keep the last good data).
- **Mutations are async + server-backed**: booking, approvals/reject/pickup, returns, extensions,
  items, categories, rules, users, notification reads. Each `await`s the API then `refresh()`s;
  failures raise an Indonesian toast. Several return `Promise<boolean>` so callers only toast
  success when the write actually succeeded.
- **Availability**: `usedOn / availableOn / availableRange` still compute remaining stock per date
  client-side from the server's loans in `OCCUPYING` states.
- **Auto status** is the **server's** job (`sweep()` runs inside `GET /state`); the old client-side
  sweep effect was removed. H-1 reminders use `loan.remindedFor` on the server.
- **Extensions**: `requestExtension` / `decideExtension` (stored on `loan.extension`, not a status).
- **Returns**: `recordReturn` posts conditions; `Hilang` reduces `stok_total` server-side.
- **Cart**: persisted to localStorage (`pinjamin.cart`) and, when the endpoint exists, mirrored to
  the server via `PUT /me/cart` (the client stops trying the remote path after its first 404).
- **Tolong.in (Fase 5)**: `chats` (tiket bantuan) datang lewat `GET /state` (difilter peran —
  pengguna hanya melihat tiketnya sendiri, Admin semua). Methods `createTicket`, `sendChat`,
  `setChatStatus`, `markChatRead`; `unreadChats` untuk lencana nav. Halaman `tolong`/`admin-tolong`
  memakai satu komponen `Tolong.tsx` yang beradaptasi per peran.

- **Favorit**: `favs` / `toggleFav(itemId)` (Mahasiswa/Dosen; Admin tidak punya katalog pinjam).
  Disimpan per pengguna di server (`user.favorites`, `PUT /me/favorites`), dimuat lewat `GET /state`
  (`favorites`, juga di `GET /me`) saat load pertama, dengan cache `localStorage['pinjamin.favs']`.
  Update **optimistis**; bila server menjawab 404 (server lama) tetap lokal, bila gagal lain
  di-rollback + toast. Bila server mengembalikan `favorites: null`, favorit lokal lama dimigrasikan
  sekali ke server. UI: `FavButton` (`ui.tsx`) di kartu `Catalog` & `ItemDetail`, chip "♥ Favorit"
  di filter katalog, dan baris "Favorit" di panel ringkas katalog.

localStorage keys: `pinjamin.theme`, `pinjamin.wall`, `pinjamin.favs`, `pinjamin.cart`, and the
Supabase session under `pinjamin.auth`. (`pinjamin.rules` is no longer read — rules come from the
server.)

Routing is a simple `page` enum + `nav(page, param)` — **no react-router**.

## 7. Server API (`supabase/functions/server/routes.tsx`)

Hono app mounted at `/make-server-5a56c1fa`. Auth = Supabase access token in
`Authorization: Bearer`; role checks via `need(c, roles?)`; actor resolved from token.
CORS open (`origin: *`).

| Method & path | Who | Purpose |
|---|---|---|
| `GET /health` | public | liveness |
| `POST /seed` | public | one-time seed (creates Auth users, remaps ids) |
| `POST /auth/login` | public | NIM/NIP/email + password → session |
| `POST /auth/logout` | auth | logs logout |
| `GET /me` · `PUT /me` | auth | fetch / update own profile |
| `POST /me/password` | auth | change password (verifies current) |
| `POST /admin/users` | Admin | create account |
| `PUT /users/:id` | Admin | update account |
| `POST /admin/users/:id/password` | Admin | reset password |
| `GET /state` | auth | full app state snapshot (role-filtered; also returns `me`, `cart`, `cartDates`, `favorites`, `chats`; setiap panggilan memperbarui `lastSeen` pengguna = denyut kehadiran) |
| `PUT /me/cart` | auth | persist the signed-in user's cart + cart dates (in the user record) |
| `PUT /me/favorites` | auth | simpan daftar favorit `{ favorites: string[] }` (maks 200, array string; duplikat & barang yang sudah tidak ada dibuang; 400 bila tidak valid). `DELETE /items/:id` juga memangkas id itu dari favorit semua pengguna |
| `POST /loans` | Mahasiswa/Dosen | create booking (validates rules & stock) |
| `POST /loans/:id/status` | role-based | transition (see TRANSITIONS map) |
| `POST /loans/:id/return` | Admin | record return + conditions |
| `POST /loans/:id/extension` | auth owner | request extension |
| `POST /loans/:id/extension/decide` | Dosen/Admin | approve/reject extension |
| `PUT /items/:id` · `DELETE /items/:id` | Admin | item upsert / delete |
| `PUT /categories` | Admin | category + item updates |
| `PUT /rules` | Admin | update business rules |
| `POST /notifs/read` | auth | mark notifications read |
| `POST /chats` | Mahasiswa/Dosen | buat tiket Tolong.in (+ pesan pertama); notif ke Admin |
| `POST /chats/:id/messages` | pemilik/Admin | kirim balasan pada tiket |
| `POST /chats/:id/status` | pemilik/Admin | ubah status tiket (Terbuka ⇄ Selesai) |
| `DELETE /chats/:id` | pemilik/Admin | hapus tiket |
| `POST /chats/read` | auth | tandai pesan orang lain pada tiket sebagai dibaca |
| `GET /admin/activity` | Admin | activity log (semua kejadian; filter di klien) |
| `GET /admin/notifs` | Admin | riwayat notifikasi global + jumlah penerima/pembaca + `canDelete` (true bila `byId === me.id`) |
| `POST /admin/notifs` | Admin | kirim notifikasi global (`type`: Peringatan/Pesan/Info); hormati `recipientIds` untuk subset penerima |
| `DELETE /admin/notifs/:id` | Admin | hapus broadcast + notifikasi penerimanya; **403** bila bukan pengirimnya |
| `GET /admin/dump` | Admin | dump all KV collections |

`TRANSITIONS`: `Disetujui` from `[Menunggu]` by Dosen/Admin; `Ditolak` same; `Dipinjam` from
`[Disetujui]` by Admin; `Dibatalkan` from `[Menunggu,Disetujui]` by anyone (owner or Admin).

KV collections (`logic.tsx`): `users, items, categories, loans, notifs, rules, activity, chats, broadcasts`.

`today()` on the server uses **UTC+7 (WIB)** so "today" matches Indonesian users.

## 8. Design system / conventions

- **Flat UI**: solid canvas/surfaces, neutral borders, minimal shadow, and no backdrop blur,
  refraction, liquid interaction, or animated mesh. Legacy class names such as `.glass`,
  `.lg-rim`, and `.liquid` can remain in JSX as compatibility hooks, but resolve to flat/no-op
  styles in `src/index.css`.
- Theme tokens defined in `@theme` and `:root`/`.dark` in `src/index.css`; use Tailwind utilities
  like `bg-primary`, `text-ink`, `text-ink-2`, `bg-canvas`.
- Dark mode via `.dark` class on `<html>` + `@custom-variant dark`.
- Adaptive color: time-of-day (`data-tod`), wallpaper (`data-wall`) drive `--logo-*`, mesh, blobs.
- Code style: mostly **single quotes**, no semicolons in `src/App.tsx`/`store.tsx`, but server
  files use double quotes + semicolons. Match the file you're editing.
- Default-export components. `@/*` alias → `src/*`.

### Fase 7 — foto & tema warna (2026-10-05) — SELESAI & terverifikasi
Empat permintaan: (1) Admin bisa menambahkan **foto barang**, (2) semua pengguna bisa memasang
**foto profil**, (3) **latar warna kustom** (solid + gradien 2 warna, *dynamic color changing*),
(4) **tema warna beranimasi** + **cache foto latar** yang diunggah.

- **Penyimpanan foto (Supabase Storage)**: bucket publik `pinjamin-photos` dibuat otomatis oleh
  Edge Function saat unggahan pertama. Database hanya menyimpan **URL pendek**, jadi payload
  `GET /state` tetap ringan. Rute baru `POST /photos` (semua pengguna yang login): body
  `{ dataUrl, kind }` dengan `kind: "avatar" | "item"` — `item` **hanya Admin (403)**. Validasi:
  data URL `png/jpeg/webp`, 64 B–3 MB. Server mengunggah byte ke Storage lalu mengembalikan
  `url` publik; dicatat ke log sebagai `foto_diunggah`.
- **Model**: `User.foto` dan `Item.foto` (URL). `publicUser` menyertakan `foto`; `PUT /me` menerima
  `foto` (string kosong = hapus). `PUT /items/:id` sudah menyimpan seluruh body, jadi `foto` ikut
  tersimpan tanpa perubahan rute.
- **Klien**: helper `src/lib/image.ts` → `readImage(file, max, quality, square)` (perkecil di canvas,
  opsi potong tengah untuk avatar). `store.uploadPhoto(file, kind)` mengunggah dan mengembalikan URL.
  `Avatar` kini menerima `src`, `ItemThumb` menerima `foto` (dengan tinggi cadangan otomatis bila
  pemanggil memakai `h-auto` / tanpa tinggi, agar thumbnail kecil seperti `size-8` tidak berubah).
  Titik pakai yang diberi foto: `Profile` (avatar + tombol Ganti/Hapus), `AdminItems` (unggah di
  form + thumbnail daftar & tabel), `Catalog`, `ItemDetail`, `CartPanel`, `LoanDetail`,
  `AdminUsers`, `AdminReturns`, `LoanQueue`, `Shell`.
- **Latar warna kustom**: `Wallpaper` diperluas (`color`, `color2`, `anim`) dan `WallId` menambah
  `solid` + `gradient`. `App.Mesh` merender `.mesh-color` dengan latar `--wall-bg` (warna solid atau
  `linear-gradient(135deg, …)`); `data-wall-tone` dihitung dari luminansi warna untuk menaikkan
  cadar (`.mesh-dim`) bila warnanya bertabrakan dengan warna teks. Kontrol di `WallpaperPicker`
  (`<input type="color">` untuk 1–2 warna).
- **Tema warna beranimasi**: `@property --spin` + `@keyframes colorSpin` 24 s pada
  `:root.theme-anim`. Warna **aksen ikut beranimasi** (`--color-primary`, `--c-primary-pressed`,
  `--c-tint-blue`, `--logo-a`, `--logo-b`) dan blob latar bawaan diberi `hue-rotate(var(--spin))`.
  Dinonaktifkan otomatis pada `prefers-reduced-motion`. Toggle di `WallpaperPicker`.
- **Cache foto latar**: foto yang diunggah untuk latar **tidak dikirim ke server** — diperkecil
  (`readImage(f, 1600, 0.8)`) lalu disimpan di `localStorage['pinjamin.wall'].image` (cache di
  perangkat). Bila kuota `localStorage` penuh, foto tetap dipakai untuk sesi ini dan pengguna diberi tahu.
